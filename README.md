# 네이버 증권 리포트

네이버 증권 리서치 페이지의 PDF 리포트를 더 편하게 저장하는 Chrome 확장 프로그램입니다.

## 주요 기능

- 네이버 증권 리서치 PDF 개별 다운로드
- 선택한 날짜의 리포트 일괄 수집 및 ZIP 저장
- 종목분석, 시황정보, 투자정보, 산업분석, 경제분석, 채권분석 지원
- 다운로드 전 미리보기와 진행 상태 표시
- KRX 거래일 기준 최근 영업일 선택
- 파일명 및 저장 폴더 설정

## 개발

```bash
npm test
npm run lint
npm run build
```

빌드 결과물은 `dist/naver-report-extension-v0.1.0.zip`에 생성됩니다.
